# Northwind SQL Analysis

## Project Overview
This project explores employee and order data from the Northwind database using SQL and Python.

## Objectives
- Retrieve employee records using SQL SELECT statements.
- Rename columns using SQL aliases.
- Classify employees using CASE statements.
- Apply SQL string functions.
- Calculate order totals using numerical functions.
- Extract day, month, and year from order dates.

## Tools Used
- Python
- SQL
- SQLite
- Pandas
- Visual Studio Code

## Skills Demonstrated
- SQL querying and data retrieval
- Data transformation
- String manipulation
- Numerical calculations
- Database connections

- `SQL_Lab.ipynb`: Contains the SQL queries and Python code.
